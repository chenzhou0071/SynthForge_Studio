# SynthForge Studio P5：云 3D 建模模式实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** blender 区云建模模式闭环：云模式精炼提示词草稿 → 服务商选择 → Tripo / 腾讯混元3D（TC3 签名）/ 自定义三个适配器提交任务 → 轮询进度（`task.progress`）→ 下载 GLB 落盘 → `asset.created` 预览。未配置密钥时发送即拒绝（P4 已完成检查）。

**Architecture:** `Cloud3dProvider` 抽象提交/轮询；三个适配器只负责协议差异（Tripo Bearer、混元 TC3-HMAC-SHA256、自定义 POST /task + GET /task/{id}）；`Cloud3dService` 统一编排轮询定时器、进度广播、下载与落盘，与 P4 的 folderPick / AssetLibrary 复用。

**规格映射：** 5.2 云模式改写目标、7.1 3D 模型页字段、8.4 云适配层、8.6 下载策略（GLB 优先）。

**依赖：** P4（folderPick、AssetLibrary、聊天链路）。

## Global Constraints

- 三家协议统一产出 **GLB**（下载后落盘 `<目标目录>/<name>.glb`；导入 Unity 时的 glb→fbx 转换在 P6 实现）。
- 轮询间隔 3s，最长 10 分钟；错误三分类：网络错误（可重试）、服务端业务错误（展示 message）、超时。
- 进度事件：`task.progress {area:"blender", taskId, percent, state}`，state ∈ `queued|running|retrying|success|failed`；`taskId` 为服务商作业号（提交前为空串）。
- TC3 签名与官方示例行为对齐；签名时间戳取 UTC。
- 云模式总结 agent 改用**精炼模板**（主体描述 + 风格关键词 + 负面词），与低模模板分离。

```cpp
#include "core/cloud3d/Tc3Signature.h"

#include <QCryptographicHash>
#include <QDateTime>
#include <QMessageAuthenticationCode>
#include <QStringList>

QByteArray hmacSha256(const QByteArray& key, const QByteArray& message)
{
    return QMessageAuthenticationCode::hash(message, key, QCryptographicHash::Sha256);
}

QString tc3Authorization(const QString& secretId, const QString& secretKey,
                         const QString& service, const QString& host,
                         const QByteArray& payload, qint64 unixSeconds)
{
    const QDateTime utc = QDateTime::fromSecsSinceEpoch(unixSeconds, QTimeZone::UTC);
    const QString date = utc.date().toString("yyyy-MM-dd");
    const QString dateTime = utc.toString("yyyy-MM-dd'T'HH:mm:ss'Z'");

    const QByteArray hashedPayload =
        QCryptographicHash::hash(payload, QCryptographicHash::Sha256).toHex();
    const QString canonicalRequest = QStringList{
        "POST", "/", "",
        "content-type:application/json; charset=utf-8\nhost:" + host + "\n",
        "content-type;host", QString::fromLatin1(hashedPayload)}.join('\n');

    const QString stringToSign = QStringList{
        "TC3-HMAC-SHA256", QString::number(unixSeconds), date + "/" + service + "/tc3_request",
        QString::fromLatin1(QCryptographicHash::hash(canonicalRequest.toUtf8(),
                                                     QCryptographicHash::Sha256)
                                .toHex())}.join('\n');

    const QByteArray secretDate = hmacSha256(("TC3" + secretKey).toUtf8(), date.toUtf8());
    const QByteArray secretService = hmacSha256(secretDate, service.toUtf8());
    const QByteArray secretSigning = hmacSha256(secretService, "tc3_request");
    const QString signature = QString::fromLatin1(
        hmacSha256(secretSigning, stringToSign.toUtf8()).toHex());

    return QStringLiteral(
               "TC3-HMAC-SHA256 Credential=%1/%2/%3/tc3_request, "
               "SignedHeaders=content-type;host, Signature=%4")
        .arg(secretId, date, service, signature);
}
```

> 头部另发 `X-TC-Timestamp`（秒）、`X-TC-Version: 2023-07-14`、`X-TC-Region`；`dateTime` 变量用于 `X-TC-Timestamp` 不一致校验的调试日志。

```cpp
void TripoProvider::submit(const QString& prompt, const QString& model)
{
    QJsonObject body{{"type", "text_to_model"}, {"prompt", prompt}};
    if (!model.isEmpty())
        body.insert("model_version", model);
    QNetworkRequest req(QUrl("https://api.tripo3d.ai/v2/openapi/task"));
    req.setRawHeader("Authorization", "Bearer " + m_apiKey.toUtf8());
    req.setHeader(QNetworkRequest::ContentTypeHeader, "application/json");
    auto* reply = m_nam.post(req, QJsonDocument(body).toJson(QJsonDocument::Compact));
    connect(reply, &QNetworkReply::finished, this, [this, reply]() {
        const QJsonObject obj = QJsonDocument::fromJson(reply->readAll()).object();
        reply->deleteLater();
        const QString taskId = obj.value("data").toObject().value("task_id").toString();
        if (taskId.isEmpty()) {
            emit failed(obj.value("message").toString("submit failed"));
            return;
        }
        emit submitted(taskId);
    });
}
```

**Interfaces:**
- `class Cloud3dService : QObject { Cloud3dService(SettingsStore*, AssetLibrary*, QObject* parent = nullptr); void start(const QString& prompt, const QString& targetFolder); bool canRetry() const; bool retry(); void cancel(); bool isRunning() const; }`（`targetFolder` 为资产库相对目录，空串=库根）
- 流程：按设置构造 provider → `submit` → 3s `QTimer` 轮询 → 广播 `task.progress` → success 后 `QNetworkAccessManager` 下载 `modelUrl` → 写入 `<targetFolder>/<sanitized>.glb` → `asset.created` + `fileTree.changed`。
- 失败重试：网络错误最多 3 次（间隔 5s，`failed` 前缀 `retryable:`）；业务错误立即 `error.card {reason:"cloud3d-failed", message}` 并停止轮询；两者都保留 `retry()` 手动重试。
- 取消：`cancel()` 停轮询并置 `m_cancelled`，迟到的 provider/下载回调全部丢弃；广播 `error.card {reason:"user-cancelled"}`。`chat.cancel {area}` 在 P2 基础上扩展：先 `cancelArea(area)`，blender 区云任务在跑时再 `m_cloud->cancel()`。
- CoreApp 接线（本任务内完成）：`progress → task.progress`、`errorCard → error.card`、`assetCreated → asset.created + fileTree.changed`（前端错误卡/文件树不直连 service）。
- `retry()` 语义：已拿到 `taskId` → 只续轮询（不重复提交扣费）；无 `taskId`（提交阶段失败）→ 用上次 prompt 重新提交。`CoreApp` 的 `chat.retry` 优先分发：`last.mode=="cloud3d" && m_cloud->canRetry()` → `m_cloud->retry()`，否则回落 P2 的 `handleChatSend(last, false)`。

```cpp
class Cloud3dService : public QObject
{
    Q_OBJECT
public:
    Cloud3dService(SettingsStore* settings, AssetLibrary* library, QObject* parent = nullptr);
    void start(const QString& prompt, const QString& targetFolder);
    bool canRetry() const;
    bool retry();
    void cancel();                       // 停轮询 + 丢弃迟到回调，广播 user-cancelled
    bool isRunning() const { return m_running; }

signals:
    void progress(const QString& taskId, const QString& state, int percent);
    void assetCreated(const QString& glbPath);
    void errorCard(const QString& reason, const QString& message);

private:
    void broadcast(const QString& state, int percent);
    void downloadModel(const QString& url);

    SettingsStore* m_settings;
    AssetLibrary* m_library;
    std::unique_ptr<Cloud3dProvider> m_provider;
    QNetworkAccessManager m_nam;         // 下载与适配器共用
    QTimer m_pollTimer;
    QElapsedTimer m_elapsed;             // 10 分钟总超时
    QString m_lastPrompt;
    QString m_taskId;
    QString m_targetDir;
    int m_attempts = 0;
    bool m_running = false;
    bool m_cancelled = false;
};
```

```cpp
void Cloud3dService::start(const QString& prompt, const QString& targetFolder)
{
    m_lastPrompt = prompt;
    m_targetDir = targetFolder.isEmpty() ? m_library->root()
                                         : m_library->absoluteFor(targetFolder);
    m_taskId.clear();
    m_attempts = 0;
    m_cancelled = false;
    m_running = true;
    m_elapsed.restart();

    const QJsonObject cloud = m_settings->data().value("cloud3d").toObject();
    const QString providerId = cloud.value("provider").toString("tripo");
    if (providerId == "tripo") {
        const QJsonObject cfg = cloud.value("tripo").toObject();
        m_provider.reset(new TripoProvider(cfg.value("apiKey").toString(),
                                           cfg.value("version").toString()));
    } else if (providerId == "hunyuan") {
        const QJsonObject cfg = cloud.value("hunyuan").toObject();
        m_provider.reset(new HunyuanProvider(cfg.value("secretId").toString(),
                                             cfg.value("secretKey").toString(),
                                             cfg.value("region").toString("ap-guangzhou"),
                                             cfg.value("model").toString()));
    } else {
        const QJsonObject cfg = cloud.value("custom").toObject();
        m_provider.reset(new CustomProvider(cfg.value("baseUrl").toString(),
                                            cfg.value("apiToken").toString()));
    }

    connect(m_provider.get(), &Cloud3dProvider::submitted, this,
            [this](const QString& taskId) {
                if (m_cancelled)             // 取消后才返回的提交结果直接丢弃
                    return;
                m_taskId = taskId;
                broadcast("queued", 0);
                m_pollTimer.start(3000);
            });
    connect(m_provider.get(), &Cloud3dProvider::status, this,
            [this](const Cloud3dStatus& status) {
                if (m_cancelled)
                    return;
                if (m_elapsed.elapsed() > 10 * 60 * 1000) {
                    m_pollTimer.stop();
                    m_running = false;
                    emit errorCard("cloud3d-failed", QStringLiteral("生成超时（10 分钟）"));
                    return;
                }
                broadcast(status.state, status.percent);
                if (status.state == "success") {
                    m_pollTimer.stop();
                    downloadModel(status.modelUrl);
                } else if (status.state == "failed") {
                    m_pollTimer.stop();
                    m_running = false;
                    emit errorCard("cloud3d-failed", status.error);
                }
            });
    connect(m_provider.get(), &Cloud3dProvider::failed, this,
            [this](const QString& reason) {
                if (m_cancelled)
                    return;
                if (reason.startsWith("retryable:") && m_attempts < 3) {
                    ++m_attempts;
                    broadcast("retrying", 0);
                    QTimer::singleShot(5000, this, [this] {
                        if (m_taskId.isEmpty())
                            m_provider->submit(m_lastPrompt, QString());
                        else
                            m_provider->poll(m_taskId);
                    });
                    return;
                }
                m_pollTimer.stop();
                m_running = false;
                emit errorCard("cloud3d-failed", reason);
            });
    m_provider->submit(prompt, QString());
}

bool Cloud3dService::canRetry() const
{
    return !m_lastPrompt.isEmpty();
}

bool Cloud3dService::retry()
{
    if (m_lastPrompt.isEmpty())
        return false;
    m_cancelled = false;
    m_running = true;
    m_elapsed.restart();
    if (!m_taskId.isEmpty()) {
        // 已提交过：只续轮询，避免重复提交扣费
        m_attempts = 0;
        broadcast("running", 0);
        m_pollTimer.start(3000);
        return true;
    }
    // 提交阶段失败：用上次参数重新提交
    m_attempts = 0;
    broadcast("queued", 0);
    m_provider->submit(m_lastPrompt, QString());
    return true;
}

void Cloud3dService::cancel()
{
    if (!m_running)
        return;
    m_running = false;
    m_cancelled = true;
    m_pollTimer.stop();
    m_taskId.clear();            // 取消后 chat.retry 走重新提交（旧作业已放弃）
    emit errorCard("user-cancelled", QString());
}

static QString sanitize(const QString& input)
{
    QString out;
    for (const QChar ch : input) {
        if (ch.isLetterOrNumber() && ch.unicode() < 128)
            out.append(ch);
        else if (ch == ' ' || ch == '-' || ch == '_')
            out.append('-');
    }
    return out.isEmpty() ? QStringLiteral("model") : out;
}

void Cloud3dService::downloadModel(const QString& url)
{
    auto* reply = m_nam.get(QNetworkRequest(QUrl(url)));
    connect(reply, &QNetworkReply::finished, this, [this, reply]() {
        const QByteArray data = reply->readAll();
        const bool ok = reply->error() == QNetworkReply::NoError && !data.isEmpty();
        reply->deleteLater();
        if (m_cancelled)
            return;
        if (!ok) {
            m_running = false;
            emit errorCard("cloud3d-failed", QStringLiteral("下载 GLB 失败"));
            return;
        }
        const QString name = sanitize(m_lastPrompt.left(24)) + "-"
                             + QDateTime::currentDateTime().toString("HHmmss") + ".glb";
        QDir().mkpath(m_targetDir);
        const QString path = QDir(m_targetDir).filePath(name);
        QFile file(path);
        if (!file.open(QIODevice::WriteOnly) || file.write(data) != data.size()) {
            m_running = false;
            emit errorCard("cloud3d-failed", QStringLiteral("写入 GLB 失败"));
            return;
        }
        file.close();
        m_running = false;
        broadcast("success", 100);
        emit assetCreated(path);
    });
}
```
