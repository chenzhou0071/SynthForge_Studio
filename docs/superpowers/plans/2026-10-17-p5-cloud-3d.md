# SynthForge Studio P5：云 3D 建模模式实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** blender 区云建模模式闭环：云模式精炼提示词草稿 → 服务商选择 → Tripo / 腾讯混元3D（TC3 签名）/ 自定义三个适配器提交任务 → 轮询进度（`task.progress`）→ 下载 GLB 落盘 → `asset.created` 预览。未配置密钥时发送即拒绝（P4 已完成检查）。

**Architecture:** `Cloud3dProvider` 抽象提交/轮询；三个适配器只负责协议差异（Tripo Bearer、混元 TC3-HMAC-SHA256、自定义 POST /task + GET /task/{id}）；`Cloud3dService` 统一编排轮询定时器、进度广播、下载与落盘，与 P4 的 folderPick / AssetLibrary 复用。

**规格映射：** 5.2 云模式改写目标、7.1 3D 模型页字段、8.4 云适配层、8.6 下载策略（GLB 优先）。

**依赖：** P4（folderPick、AssetLibrary、聊天链路）。

## Global Constraints

- 三家协议统一产出 **GLB**（下载后落盘 `<目标目录>/<name>.glb`；导入 Unity 时的 glb→fbx 转换在 P6 实现）。
- 轮询间隔 3s，最长 10 分钟；错误三分类：网络错误（可重试）、服务端业务错误（展示 message）、超时。
- 进度事件：`task.progress {area:"blender", taskId, percent, state}`，state ∈ `queued|running|success|failed`。
- TC3 签名与官方示例行为对齐；签名时间戳取 UTC。
- 云模式总结 agent 改用**精炼模板**（主体描述 + 风格关键词 + 负面词），与低模模板分离。

```cpp
#include "core/cloud3d/Tc3Signature.h"

#include <QCryptographicHash>
#include <QDateTime>
#include <QMessageAuthenticationCode>
#include <QStringList>

QByteArray hmacSha256(const QByteArray& key, const QByteArray& message)
{
    return QMessageAuthenticationCode::hash(message, key, QCryptographicHash::Sha256);
}

QString tc3Authorization(const QString& secretId, const QString& secretKey,
                         const QString& service, const QString& host,
                         const QByteArray& payload, qint64 unixSeconds)
{
    const QDateTime utc = QDateTime::fromSecsSinceEpoch(unixSeconds, QTimeZone::UTC);
    const QString date = utc.date().toString("yyyy-MM-dd");
    const QString dateTime = utc.toString("yyyy-MM-dd'T'HH:mm:ss'Z'");

    const QByteArray hashedPayload =
        QCryptographicHash::hash(payload, QCryptographicHash::Sha256).toHex();
    const QString canonicalRequest = QStringList{
        "POST", "/", "",
        "content-type:application/json; charset=utf-8\nhost:" + host + "\n",
        "content-type;host", QString::fromLatin1(hashedPayload)}.join('\n');

    const QString stringToSign = QStringList{
        "TC3-HMAC-SHA256", QString::number(unixSeconds), date + "/" + service + "/tc3_request",
        QString::fromLatin1(QCryptographicHash::hash(canonicalRequest.toUtf8(),
                                                     QCryptographicHash::Sha256)
                                .toHex())}.join('\n');

    const QByteArray secretDate = hmacSha256(("TC3" + secretKey).toUtf8(), date.toUtf8());
    const QByteArray secretService = hmacSha256(secretDate, service.toUtf8());
    const QByteArray secretSigning = hmacSha256(secretService, "tc3_request");
    const QString signature = QString::fromLatin1(
        hmacSha256(secretSigning, stringToSign.toUtf8()).toHex());

    return QStringLiteral(
               "TC3-HMAC-SHA256 Credential=%1/%2/%3/tc3_request, "
               "SignedHeaders=content-type;host, Signature=%4")
        .arg(secretId, date, service, signature);
}
```

> 头部另发 `X-TC-Timestamp`（秒）、`X-TC-Version: 2023-07-14`、`X-TC-Region`；`dateTime` 变量用于 `X-TC-Timestamp` 不一致校验的调试日志。

```cpp
struct Cloud3dStatus
{
    QString state;     // queued | running | success | failed
    int percent = 0;
    QString modelUrl;  // success 时有效
    QString error;
};

class Cloud3dProvider : public QObject
{
    Q_OBJECT
public:
    using QObject::QObject;
    virtual void submit(const QString& prompt, const QString& model) = 0;
    virtual void poll(const QString& taskId) = 0;
signals:
    void submitted(const QString& taskId);
    void status(const Cloud3dStatus& status);
    void failed(const QString& error);
};
```

- `TripoProvider(QString apiKey, QString version)`：`POST {base}/v2/openapi/task`，body `{"type":"text_to_model","prompt":...,"model_version":...}`，Bearer；响应 `data.task_id`。`GET {base}/v2/openapi/task/{id}` → `data.status/progress/output.p.url`。
- `CustomProvider(QString baseUrl, QString apiToken)`：`POST {base}/task` → `{task_id}`；`GET {base}/task/{id}` → `{status, progress, model_url, error}`（规格 7.1 自定义协议约定）。

- [ ] **Step 1: 实现 TripoProvider 核心**

```cpp
void TripoProvider::submit(const QString& prompt, const QString& model)
{
    QJsonObject body{{"type", "text_to_model"}, {"prompt", prompt}};
    if (!model.isEmpty())
        body.insert("model_version", model);
    QNetworkRequest req(QUrl("https://api.tripo3d.ai/v2/openapi/task"));
    req.setRawHeader("Authorization", "Bearer " + m_apiKey.toUtf8());
    req.setHeader(QNetworkRequest::ContentTypeHeader, "application/json");
    auto* reply = m_nam.post(req, QJsonDocument(body).toJson(QJsonDocument::Compact));
    connect(reply, &QNetworkReply::finished, this, [this, reply]() {
        const QJsonObject obj = QJsonDocument::fromJson(reply->readAll()).object();
        reply->deleteLater();
        const QString taskId = obj.value("data").toObject().value("task_id").toString();
        if (taskId.isEmpty()) {
            emit failed(obj.value("message").toString("submit failed"));
            return;
        }
        emit submitted(taskId);
    });
}
```

轮询解析：`status` 映射 + `progress` 取整 + success 时 `data.output.p.url`；网络错误 emit `failed` 但由 Service 决定重试（`failed` 消息带 `retryable:` 前缀约定）。

- 请求体：`{"Prompt": prompt}`；响应：`Response.JobId`；查询：`Response.Status`（`WAIT|RUN|DONE|FAIL`）、`Response.ResultFile3Ds[0].File3D`（URL）。

- [ ] **Step 1: 实现请求封装**

```cpp
void HunyuanProvider::sendSigned(const QString& action, const QJsonObject& body,
                                 std::function<void(const QJsonObject&)> onResponse)
{
    const QByteArray payload = QJsonDocument(body).toJson(QJsonDocument::Compact);
    const qint64 now = QDateTime::currentSecsSinceEpoch();
    QNetworkRequest req(QUrl(QStringLiteral("https://hunyuan.tencentcloudapi.com")));
    req.setHeader(QNetworkRequest::ContentTypeHeader, "application/json; charset=utf-8");
    req.setRawHeader("Authorization",
                     tc3Authorization(m_secretId, m_secretKey, "hunyuan",
                                      "hunyuan.tencentcloudapi.com", payload, now).toUtf8());
    req.setRawHeader("X-TC-Action", action.toUtf8());
    req.setRawHeader("X-TC-Version", "2023-07-14");
    req.setRawHeader("X-TC-Timestamp", QByteArray::number(now));
    req.setRawHeader("X-TC-Region", m_region.toUtf8());

    auto* reply = m_nam.post(req, payload);
    connect(reply, &QNetworkReply::finished, this, [reply, onResponse]() {
        const QJsonObject obj = QJsonDocument::fromJson(reply->readAll()).object();
        reply->deleteLater();
        onResponse(obj.value("Response").toObject());
    });
}
```

状态映射：`WAIT→queued`、`RUN→running`（percent 未知固定 50）、`DONE→success`（`ResultFile3Ds.first.File3D`）、`FAIL→failed`（`Error.Message`）。

```cpp
void Cloud3dService::start(const QString& prompt, const QString& targetFolder)
{
    m_prompt = prompt;
    m_targetDir = targetFolder.isEmpty() ? m_library->root() : m_library->absoluteFor(targetFolder);
    m_attempts = 0;

    const QJsonObject cloud = m_settings->data().value("cloud3d").toObject();
    const QString providerId = cloud.value("provider").toString("tripo");
    if (providerId == "tripo") {
        const QJsonObject cfg = cloud.value("tripo").toObject();
        m_provider.reset(new TripoProvider(cfg.value("apiKey").toString(),
                                           cfg.value("version").toString()));
    } else if (providerId == "hunyuan") {
        const QJsonObject cfg = cloud.value("hunyuan").toObject();
        m_provider.reset(new HunyuanProvider(cfg.value("secretId").toString(),
                                             cfg.value("secretKey").toString(),
                                             cfg.value("region").toString("ap-guangzhou"),
                                             cfg.value("model").toString()));
    } else {
        const QJsonObject cfg = cloud.value("custom").toObject();
        m_provider.reset(new CustomProvider(cfg.value("baseUrl").toString(),
                                            cfg.value("apiToken").toString()));
    }

    connect(m_provider.get(), &Cloud3dProvider::submitted, this,
            [this](const QString& taskId) {
                m_taskId = taskId;
                broadcast("queued", 0);
                m_pollTimer.start(3000);
            });
    connect(m_provider.get(), &Cloud3dProvider::status, this,
            [this](const Cloud3dStatus& status) {
                broadcast(status.state, status.percent);
                if (status.state == "success")
                    downloadModel(status.modelUrl);
                else if (status.state == "failed")
                    emit errorCard("cloud3d-failed", status.error);
            });
    m_provider->submit(m_prompt, QString());
    m_pollTimer.setSingleShot(false);
    connect(&m_pollTimer, &QTimer::timeout, this, [this]() { m_provider->poll(m_taskId); });
}
```

落盘命名：`sanitize(m_prompt.left(24)) + "-" + QDateTime::currentDateTime().toString("HHmmss") + ".glb"`（sanitize 保留 ASCII 字母数字与 `-`）。

`CoreApp` 接线：`chat.send` cloud3d 分支检查通过后走 SummarizerAgent 云模板（`{{mode}}=cloud3d` 选择模板文件）；`draft.send` 若 `mode=="cloud3d"` → 直接触发 folderPick（不经过低模的 plan 阶段），`folderPick.submit` 后调用 `Cloud3dService::start(prompt, targetFolder)` 而非 orchestrator。
