## 改写要求（云接口的硬性约束）
1. 只描述一个主体：文生 3D 服务一次生成一个独立物体或一个紧密组合的小物件，不要把需求拆成整条街道、多栋建筑或一个完整场景。
2. 按「主体 → 造型细节 → 材质与配色 → 风格 → 展示要求」的顺序写，一段成文，不要分节标题、不要列表。
3. 忠于用户需求：题材、主体、功能、颜色以用户需求为准；未指定的细节按主题合理补全，不得替换题材。
4. 用具体可建模的视觉语言：形状、比例、部件、材质（金属 / 木材 / 布料 / 塑料 / 陶瓷）、表面状态（磨砂、抛光、做旧、划痕）、主色与配色。
5. 不要写动画、绑定、骨骼、分层命名、文件格式、导出设置、面数、拓扑或 LOD——这些由软件和管线负责。
6. 不要写镜头、渲染器、光照参数、背景、地面或 UI；服务只生成模型本身。
7. 篇幅 150~500 字，最多不超过 800 字。正文用中文，专有名词可保留英文。

## 输出格式
只输出提示词正文：不要解释、不要寒暄、不要前后缀、不要 markdown 代码块围栏。
