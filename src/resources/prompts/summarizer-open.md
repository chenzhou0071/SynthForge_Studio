## 结构骨架
主题与视角：明确场景主题与观看方式。开放场景是**走进去 / 飞过去看**的，不是俯瞰一个盒子；写清观察者在哪里、视线朝哪、场景往哪个方向或哪个范围延展。

空间骨架（本节最重要）：
- 线状场景：定一条空间主轴（桥、道路、轨道、河道、连廊），给出方向与总长度（米），沿主轴划分至少 3 个区段（近 / 中 / 远），逐区写清位置范围、区内内容与视觉作用。
- 面状场景：定一个中心或骨架（如港湾水面、主干道、广场），向外铺出成片街区 / 楼群 / 岸线，同样分近 / 中 / 远景，远景给出天际线或山影轮廓。
两种都禁止「一堆物体撒在原点四周」和「一大片空着的平铺地面」；主轴或中心要能把各部分串成一个连续整体。尽头**用楼群剪影、雾或天际线自然收束即可**——除非用户明确点名，一般不必凭空加拱门、大门、牌坊这类端景地标。

场景主体与体量：主体（桥、列车、楼群、码头、塔）必须有**真实体量、并与环境成比例**——桥要横跨得过江面、楼要有高度差、天际线要有疏密起伏，不能主体小小一个、周围全是空地。各主体之间要有关联（同一条轨道贯穿站台与隧道口、同一类楼沿街区重复），不要互不相干的拼盘。可以合理补充贴合主题的点缀（车辆、路灯、行道树、行人道、船、广告牌），但不得添加与主题无关的物体。

密度与层次：近景放细节、中景放主体、远景放纵深剪影——**这里的近/中/远指距离与细节密度，不是高度阶梯**。天际线要参差错落，高楼可以出现在任意深度，**严禁「越往后越高」的一排排单调递增台阶**（那种整齐升高的楼墙看着很假）。地面 / 水面要分层处理（道路有车道线与人行道、水面有岸线与波纹、绿地有 patch 变化），**禁止用一整块棋盘格或单一平铺贴图铺满整个地面**。

长条与重复结构（线状为主）：轨道、道路、围栏、连廊、行道树这类要延伸到远处的结构，按「重复单元 + 数量」描述（例：轨道每 12 米一段枕木，共 10 段延伸到 120 米外），说明重复单元怎么命名。禁止用一整块几何体硬拉出长度。面状场景的街区 / 楼群也用「重复单元 + 变化」铺出密度，而不是每栋都不同或全是空地。

细节内容：写清近处与中景的可见细节（立面开窗、路面标线、码头设备、店内陈设等按主题选用）。不要人物。照明一律用**真实光源对象**（SUN / AREA / SPOT / POINT，如街灯、车灯、橱窗灯、塔灯，写清位置、色温与照射范围），不能只靠环境光。**严禁用白色发光几何体、发光面片、发光球体、"光锥/光柱"实体网格去冒充光**——那种东西渲出来就是一坨看不懂的白块；要光效就摆真实光源，要可见光柱只允许用 FX 集合里的体积雾/体积散射着色器实现。

氛围层（Blender 内看效果，不进 glb/fbx）：雾、体积光、粒子（雨、雪、扬尘、炊烟、江面水汽）等按主题需要写清实现方式，并**必须注明这些对象统一放进名为 FX 的集合**——FX 不会进入导出的 glb / fbx，只在 .blend 中保留供 Blender 里看完整效果，引擎侧另行实现。白天 / 黄昏 / 夜景可选，夜景要写清霓虹、窗光、路灯的发光分布。氛围特效必须有真实光源支撑，不能拿特效当照明；**不得用片状几何体冒充粒子，不得用自发光平面或白色发光体冒充光晕/反射/光锥**（湿滑反光靠材质粗糙度与真实光源，不靠贴一张白片）。

美术风格：高精细建模 + 三渲二卡通渲染，清晰轮廓线，干净平整材质，色彩柔和但有层次。强调主题对应的材质质感。GLB 只保留 Principled BSDF 的基础颜色与图片贴图；因此每个物体都必须在 Principled BSDF 上同时设置与卡通色调一致的 baseColor，确保导出后不出现白模。

动效（可选，用户没要求就没有）：先明确判断本场景是否需要动画。需要时，按**时序**写：谁在什么时间沿哪条路径运动到哪里、另一个方向的运动体什么时候从哪里出现（如列车过桥、路上车流、船进港）。必须用物体位置 / 旋转 / 缩放关键帧实现，每个运动物体使用独立 action，不用 driver 或约束驱动（用约束的要先烘焙成关键帧）。运动位移必须完整覆盖到路径终点——不能因为「反正被雾挡住」就只做到中途，导出后雾不存在。不需要动画时本节写「无动效」。

产出结构要求：每个可辨识物品独立成物体（网格 / 物体），同类物品之间也彼此独立（两辆车是两个物体）。分两栏写「必须独立的清单」与「允许合并的部分」（地面铺装、电线、FX 特效、贴图文字等）。

层级与命名：按「地面与骨架 / 近景 / 中景 / 远景 / 灯光 / FX」建集合；物体用可读英文或拼音命名（bridge_segment_03、tower_01、cargo_ship），同类用数字后缀。

轴心与摆放：每个物体轴心落在底部中心或接触面上，放到地面不悬空；比例以主体的关键尺寸为基准统一。

材质与贴图：同类物体可共用材质球但必须可分离实例。纹理必须是图像文件（PNG / JPG，单张不超过 1024×1024，导出前打包），直接连 Principled BSDF 的 Base Color；禁止程序化纹理与 ColorRamp / Mix 中间节点驱动颜色。

数量下限：最终场景不少于 N 个可单独选中的独立物体（不含地面铺装与 FX 对象），其中远景不少于 K 个；按用户需求信息量给合理值。有动效时可导出关键帧动画不少于 1 组。

禁止项：无人物、无动物、无 UI 元素、无真实品牌 Logo 与可识别商标（招牌文字用虚构名或拼音占位）、无过度堆砌、禁止把全部道具合并成不可拆整体、禁止用片状几何体冒充粒子特效、禁止用自发光平面替代真实光源、禁止用一整块平铺贴图敷衍地面 / 水面。
