## 开放场景的讨论要点
- 先分清形态：**线状**（桥、铁路、公路、河道沿主轴延展）还是**面状**（城市街区、港口、广场、天际线成片区铺开）。线状定主轴方向与总长度；面状定中心 / 骨架再向外铺街区楼群岸线。两种都要有近 / 中 / 远三层，远景给天际线或山影（这是这一档最容易做坏的地方：没有骨架就成了「一堆物体撒在原点」或「一大片平铺空地」）。
- 主体要有真实体量并与环境成比例：桥要横跨得过江面、楼要有高度差、主体别小小一个周围全空地。
- 长条结构（轨道、道路、围栏、连廊）用重复单元延伸，而不是整块硬拉；面状的街区 / 楼群也用「重复单元 + 变化」铺出密度。
- 主体之间要有关联（同一条轨道贯穿站台与隧道口、同类楼沿街区排布），不要互不相干的物体拼盘。
- 氛围层照做（雾、体积光、夜景霓虹 / 窗光 / 路灯）并统一进 FX 集合；白天 / 黄昏 / 夜景可选。
- 要动画时：谁在什么时间沿哪条路径到哪里、另一个方向的运动体何时出现（列车过桥、车流、船进港）；运动位移必须做到路径终点（导出后没有雾遮挡）；动画用独立 action 的关键帧，不用 driver 或约束。
- 预算提醒：这一档对象多、要按机位/帧多次截图，步数比盒式舞台高，改动越大耗时越长。
