## 结构骨架
主题与视角：明确场景主题与观察方式。以第三视角俯瞰，整体像可自由拖拽、旋转、缩放的微缩三维模型 / 小型景观。画面中不得出现任何 UI 元素（网格线、坐标轴、操作手柄、水印、边框按钮）。

底座与构图：地面为一个完整的正方形底座，所有元素都搭建在底座上。构图紧凑、层次清晰，呈现小巧、精致、可收藏的模型感。主体位于视觉中心偏一侧，形成明确的构图转折。街道或场地尺度不必大，但要有近景（路边物件）、中景（主体建筑）、远景（巷口与远处灯光）三层纵深。

场景主体：围绕用户需求写清主体构成，并列出可选的室外道具候选清单（按需选用，宁精不多）。在不改变题材和主体功能的前提下，可以合理补充贴合主题的细节——车辆、路牌、摊贩、街边杂物、远景建筑等都可以有；但不要堆与主题无关的物件，也不要用杂物硬填空白，留白处用地面材质、光影和纵深处理。

细节内容（重点）：写清主体内部 / 近处的可见细节，要求透过门窗或开敞结构能清楚看到内部，让内外形成明暗、冷暖、疏密的对比。不要人物。照明必须来自真实光源：街灯、店招灯、室内顶灯 / 台灯 / 灯带等要写清位置、色温和照射范围；室内场景必须有可见灯源，不能只靠环境光。不要默认加入飞虫、湿地面、积水等氛围元素；光粒子、光雾可以用粒子 / 着色器增强氛围，但必须有真实光源支撑，不能拿特效当照明。用户明确要求飞虫等特殊元素时才写，并注明用粒子 / 着色器实现，不得用几何体或贴图冒充。

美术风格：高精细建模 + 三渲二卡通渲染。清晰的轮廓线（外轮廓略粗、内部结构线略细），干净平整的材质表现，色彩柔和但有夜景或主题所需的层次感。强调主题对应的材质质感（金属高光、布料柔软度、木材与混凝土的粗糙度等），整体气质统一。注意：GLB 只保留 Principled BSDF 的基础颜色与图片贴图；三渲二着色、着色器描边与程序化纹理仅用于 Blender 内展示。因此每个物体都必须在 Principled BSDF 上同时设置与卡通色调一致的 baseColor，确保导出后不出现白模。

动效（细微、循环、不抢戏）：列出 3–6 个循环动效，分两类写清楚：
- 可导出：必须用物体的位置 / 旋转 / 缩放关键帧直接实现（门开合、招牌轻摆、指针转动、风扇旋转等）；每个动效使用独立的 action，首尾帧姿态一致以便无缝循环，关键帧落在场景帧范围内；不使用 driver、表达式或约束驱动。
- 仅源文件：粒子 / 自发光 / 着色器实现的氛围特效（灯光闪烁、招牌呼吸、光粒子、光雾、炊烟等，按需加入），不会进入 GLB，仅用于 Blender 内展示。
整体仍保持“静止而精致的微缩世界”观感，动态只作为生命力点缀。

产出结构要求（重要）：独立产出原则——场景中每一个可辨识的物品都必须作为独立的网格 / 独立物体产出，不得合并为单一整体模型；同类物品之间也必须彼此独立（两辆车是两个物体，三个货架是三个物体）。分两栏写明「必须独立的清单」与「允许合并的部分」（底座地面、粒子特效、电线、贴图文字等）。

层级与命名：按「底座 / 建筑 / 室外道具 / 室内道具 / 灯光 / 特效」分组建立层级；每个物体使用可读的英文或拼音命名（如 wall_01、vending_machine_02），同类物品用数字后缀区分。

轴心与摆放：每个道具的轴心落在其底部中心或与地面的接触面上，保证放到平面上不会悬空；尺寸比例统一，以主体入口高度为基准保持一致。

材质与贴图：每个独立物体可单独指定材质，同类物体允许共用材质球但必须是可分离的实例；霓虹 / 灯箱 / 发光部分使用自发光颜色单独控制。所有纹理必须是图像文件（PNG / JPG，单张不超过 1024×1024，导出前打包），直接连接 Principled BSDF 的 Base Color；禁止使用程序化纹理与 ColorRamp / Mix 等中间节点驱动颜色——GLB 只保留纯色与图片贴图。

可选扩展：如支持，请同时提供简化版 LOD 与基础碰撞体；允许单独隐藏室内、隐藏天气特效、隐藏招牌灯光，以便分层展示。

数量下限：最终场景应包含不少于 N 个可单独选中的独立物体（不含底座与特效），其中主体内部可见陈设不少于 M 个；可导出动效不少于 3 个（不含仅源文件类）。N、M 按用户需求的信息量给出合理值。
