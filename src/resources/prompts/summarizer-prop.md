## 结构骨架
主体与用途：这件资产是什么、放在什么场景里会被用到、使用者最关心哪个角度。

组成清单：逐个列出资产内的每个独立物体（书桌 → 桌面、四腿、抽屉柜、电脑、键盘、杯子、书本）。凡是能被单独拿走的东西都必须作为独立物体，不得与主体合并成一个网格；明确写出「必须独立的清单」与「允许合并的部分」（同一块布、线缆、贴图文字可合并）。

尺度与摆放：以真实尺度描述（单位米），写清主要物体的长宽高与相互位置。每个物体的轴心落在其底部中心或与地面的接触面上。**不要底座、不要地面、不要任何地平面对象**——资产之外的空处就是空处，进引擎后由使用者自己摆。

层级与命名：所有物体挂在一个根空对象下，根对象名 = 资产英文名，位置在世界原点；子物体使用可读英文或拼音命名（desk_top、mug_01），同类物品用数字后缀。

细节内容：写清近处可见细节（木纹、缝线、磨损、屏幕内容）。照明只能来自属于物体本身的功能光源（台灯、屏幕自发光材质、灯管），**不要环境光、不要太阳光、不要世界环境设置**。

动效（可选）：道具通常不动。确有开合 / 旋转部件时，用物体自身的位置 / 旋转 / 缩放关键帧实现，每个动效使用独立 action，首尾姿态一致，不使用 driver、表达式或约束驱动。用户没要求就写「无动效」。

美术风格：高精细建模 + 三渲二卡通渲染，清晰轮廓线，干净平整材质，强调主题对应的材质质感。GLB 只保留 Principled BSDF 的基础颜色与图片贴图，三渲二着色与程序化纹理仅用于 Blender 内展示，因此每个物体都必须在 Principled BSDF 上同时设置与卡通色调一致的 baseColor，确保导出后不出现白模。

材质与贴图：同类物体允许共用材质球但必须是可分离实例。所有纹理必须是图像文件（PNG / JPG，单张不超过 1024×1024，导出前打包），直接连接 Principled BSDF 的 Base Color；禁止程序化纹理与 ColorRamp / Mix 等中间节点驱动颜色。

禁止项：无底座、无地面、无环境光、无人物、无动物、无 UI 元素、无真实品牌 Logo、**不做雾 / 粒子 / 光雾 / 飞虫 / 湿地面等任何氛围特效**、禁止把可分离的小件合并成一个不可拆整体、禁止用片状几何体冒充粒子特效。
